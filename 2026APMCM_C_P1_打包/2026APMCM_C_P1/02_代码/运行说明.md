## 实现细节（便于校对）

### 秩检验
- `fast_rank()`：`argsort` + 并列取平均秩；
- KW 的 tie correction：$H \div \left(1-\frac{\sum(t^3-t)}{N^3-N}\right)$；
- df=2 时卡方 CDF 有闭式 $p=e^{-H/2}$，故无需查表；
- MWU 用正态近似 + 并列校正；对二元变量（F02/脉冲串）正态近似失效，改用置换 p。

### 置换检验
- PERMANOVA：$SS_{total}=\frac{1}{n}\sum_{i<j}d_{ij}^2$，$SS_{within}=\sum_g\frac{1}{n_g}\sum_{i<j\in g}d_{ij}^2$，$F=\frac{(SS_T-SS_W)/(a-1)}{SS_W/(n-a)}$；
- 置换 9999 次，p = (count+1)/(B+1)，最小可分辨 p ≈ 1e-4；
- PERMDISP：各组到质心的平均距离，置换检验其组间差异。

### 逻辑回归 / softmax
- 梯度下降（lr=0.5，4000–8000 次），L2 正则 λ=1e-2；
- 标准化在**每折训练集内部**计算，避免信息泄漏；
- 全部指标为留一交叉验证（LOO）结果。

### AUC
- 用 Mann-Whitney 秩公式，并列按 0.5 计；
- 置信区间：分层 bootstrap（2000 次），分别对正负类重采样；
- 配对 bootstrap 差异检验：同一重采样索引下计算两个 AUC 之差。

### 遗传的坑（已处理）
- **pandas 3.0 的 `.values` 返回 `StringArray` 而非 numpy 数组**，须用 `np.array(series.tolist(), dtype=object)`；
- matplotlib 中文需注册字体（`msyh.ttc`），并设 `axes.unicode_minus=False`。
