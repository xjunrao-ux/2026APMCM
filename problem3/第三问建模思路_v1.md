# 海上回放实验中，什么声音会引起怎样的群体响应？

## 问题与观测单位

C 题英文题面第 3 页要求比较自然叫声与控制声，给出一次播放后三种行为的组合概率，并在典型群体规模和三个距离上预测启动时间。每行代表对一个企鹅群的一次播放。用 Data02 单独拟合，保留每次播放自己的距离、群体规模和情境，所有推断与验证都以实验编号 expID 为分组单位。

## 拟合前的处理

1. 核对每个实验的两条记录、录音与叫声的对应关系、八种组合频数、缺失及逻辑矛盾。总体响应采用 ResponseYesNo。抬头 H、鸣叫 V、接近 A 采用各自 YesNo。按字段定义分别估计总体响应与至少一种目标行为出现的概率，两者逐行相同才共用拟合。
2. 从播放开始计时，到群内第一只企鹅开始该行为为止；满 60 秒仍未观察到该行为记作右删失。整数记录的 0 秒抬头属于即时响应，以首个半秒的区间处理。标记为无行为而仍有时间的行保留原值，主分析按标记；另以时间字段存在为事件复核。播放前后鸣叫次数分别对应前后各一分钟。[原研究方法、表 1](https://ore.eu/article/view/1538/version/2510)
3. 比较四类声音，控制组为参照。三种自然声整体对比预先定为等权，标准化时使用共同的实测协变量分布。分清原始样本率、调整概率、优势比、实验组层面的响应与个体响应。

## 四项模型

| 估计对象 | 第一版实现与取舍 | 输出 |
|---|---|---|
| 总体响应 | 配对 McNemar 精确检验给出设计内比较。边际 Logistic 回归控制 CallType、Context、距离与群体规模，按实验整组抽样；比较加性、自然声与情境交互、完整叫声与情境交互的组外预测。随机截距模型作对照。 | 调整概率、标准化概率差与优势比、距离和群体规模的变化 |
| 八种行为组合 | 先估计至少一种目标行为的概率，再对有目标行为的记录拟合七类带收缩的多项 Logistic。八类总体概率为 1−p 和 p×qₖ。配对内交换整条组合标签，检验两种刺激的分布差异。 | 八类频数和概率、各叫声相对控制的组合概率差、条件构成 |
| 首次响应时间 | 以“60 秒内出现该行为的概率 × 已发生时的时间分布”刻画累积发生率。发生概率由八类组合求和。已响应时间采用限于窗口的对数正态时间模型；对仅有少数事件的接近行为简化时间部分。另以含右删失的单分布 AFT 检查模型假设。 | 窗内响应／无响应概率、响应者中位潜伏期、限制平均等待时间 RMST；注明无事件或超出观测支持的单元 |
| 响应强度 | 每个指标按实测值是否大于零分两部分。对鸣叫次数比较零截断 Poisson 与负二项，控制播放前鸣叫数；对抬头时间估计 0 至 60 秒内的条件均值；对接近时间合并少量正观测估计均值。 | 正值发生率、条件均值与总体期望（前两项之积），注明秒或次 |

## 数值预测与验算

按 Data02 的群体规模中位数，交叉取三类自然叫声及对照、50／100／150 m 和三种情境，另按实测情境构成给出便于阅读的综合预测。时间表同时保留实测样本支持；样本里没有响应的单元明确标注。RMST 为窗口内生存概率的积分，未响应的试次贡献完整的 60 秒等待。条件时间仅解释已经出现相应行为的试次。

固定随机种子，交叉验证按 expID 分折，区间按 expID 整组重抽样。检查概率取值、概率和、预期强度恒等式、时间范围、样本外校准，并把所有调整、模型选择和异常处理写入结果目录。第四问可按叫声、情境、距离、群体规模读取预测；换算个体数另需响应个体比例假设。
