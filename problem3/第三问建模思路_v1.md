# 海上回放实验中，什么声音会引起怎样的群体响应？

## 问题与观测单位

C 题英文题面第 3 页要求比较自然叫声与控制声，给出一次播放后三种行为的组合概率，并在典型群体规模和三个距离上预测启动时间。每行代表对一个企鹅群的一次播放。用 Data02 单独拟合，保留每次播放自己的距离、群体规模和情境，所有推断与验证都以实验编号 expID 为分组单位。

## 拟合前的处理

1. 核对每个实验的两条记录、录音与叫声的对应关系、八种组合频数、缺失及逻辑矛盾。总体响应采用 ResponseYesNo；抬头 H、鸣叫 V、接近 A 采用各自 YesNo。按字段定义分别估计总体响应与至少一种目标行为出现的概率，两者逐行相同才共用拟合。
2. 从播放开始计时，到群内第一只企鹅开始该行为为止，观察窗固定为 60 秒。60 秒内出现的记为该行为发生（YesNo=1），满 60 秒仍未出现的记为该行为未发生（YesNo=0，即“无反应”）。整数记录的 0 秒抬头属于即时响应，按首个半秒（0–0.5 秒）的区间处理。播放前后鸣叫次数分别对应前后各一分钟。[原研究方法、表 1](https://ore.eu/article/view/1538/version/2510)
3. 比较四类声音，控制组为参照。三种自然声整体对比为等权，标准化时使用共同的实测协变量分布。区分原始样本率、调整概率、优势比，以及实验组层面的响应与个体响应。

## 四项模型

| 估计对象 | 实现 | 输出 |
|---|---|---|
| 总体响应 | 配对 McNemar 精确检验给出设计内比较。边际 Logistic 回归控制 CallType、Context、距离与群体规模，按实验整组抽样；在加性、自然声与情境交互、完整叫声与情境交互之间做组外预测选模。随机截距模型作对照。 | 调整概率、标准化概率差与优势比、距离和群体规模的变化 |
| 八种行为组合 | 先估计至少一种目标行为出现的概率 p，再对有响应的记录拟合七类带收缩的多项 Logistic 得到条件概率 q_k，八类概率 = [1−p, p·q_k]。配对内交换整条组合标签做置换检验。 | 八类频数和概率、各叫声相对控制的组合概率差、条件构成 |
| 首次响应时间 | 两部分模型：发生率 p = 八类组合中含该行为的概率之和；时间 = 限于 [0, 60] 秒的截断对数正态，条件在“已经发生”上。 | 窗内响应／无响应概率、响应者中位潜伏期、限制平均等待时间 RMST；注明无事件或超出观测支持的单元 |
| 响应强度 | 每个指标按实测值是否大于零分两部分。鸣叫次数比较零截断 Poisson 与负二项，控制播放前鸣叫数；抬头时间估计 0–60 秒内的条件均值；接近时间合并少量正观测估计均值。 | 正值发生率、条件均值与总体期望（前两项之积），注明秒或次 |

## 首次响应时间的 60 秒截断

首次响应时间用两部分结构刻画，两部分都严格限定在 60 秒观察窗内：

1. **发生率 p = P(60 秒内出现该行为)。** 来自八类组合概率中含该行为的组合之和。超过 60 秒仍无反应就是“无反应”，概率为 1−p，不分配任何“之后才响应”的概率。
2. **时间分布 = 截断对数正态。** 只用 60 秒内真实发生该行为的试次拟合，密度按 F(60) 归一化为 f(t)/F(60)，t ∈ (0, 60]。0 秒的即时响应按 F(0.5)/F(60) 的区间似然处理。

由此，截至第 t 秒的累计发生概率 = p × F(t)/F(60)：t=0 时为 0、t=60 时恰为 p，从不超过 p，也不外推到 60 秒之后。发生者中位潜伏期取 F(t)/F(60)=0.5 的解；RMST = 60(1−p) + p·E[T | T≤60]，其中未响应的试次贡献完整的 60 秒等待。

接近仅有 23 次事件，其时间分布合并估计；另以含右删失的单分布 AFT（对数正态、Weibull）检验时间假设。

## 数值预测与验算

按 Data02 的群体规模中位数，交叉取三类自然叫声及对照、50／100／150 m 和三种情境，另按实测情境构成给出便于阅读的综合预测。时间表同时保留实测样本支持；样本里没有响应的单元明确标注。条件时间仅解释已经出现相应行为的试次。

固定随机种子，交叉验证按 expID 分折，区间按 expID 整组重抽样。检查概率取值、概率和、预期强度恒等式、时间范围、样本外校准，并把所有调整、模型选择和异常处理写入结果目录。第四问可按叫声、情境、距离、群体规模读取预测；换算个体数另需响应个体比例假设。
