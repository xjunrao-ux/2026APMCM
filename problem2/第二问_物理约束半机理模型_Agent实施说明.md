# 1. 建模目标与总体路线

第二问不应只完成距离---相关性曲线拟合。需要形成完整链条：

1.  根据传播距离、声源频谱和传播环境，建立声信号传播模型；
2.  由接收信号的信噪比及结构畸变解释三种相关性指标；
3.  构造综合声学保真度；
4.  建立潜在识别、一般识别、可靠识别的分级阈值；
5.  计算三种叫声在重点阈值下的有效通信距离；
6.  给出距离估计不确定性、模型对照和环境敏感性分析。

采用"半机理模型"而不是完全自由的曲线拟合：

-   物理理论负责规定传播损失、频率依赖、噪声与信噪比之间的关系；
-   现有九份相关性 CSV 用于校准模型中的有效参数；
-   对数据没有提供的温湿度、噪声谱、海面几何等信息，采用有出处的参数范围或情景分析，不得伪造实测值；
-   原作者 GAM
    作为基准模型，用于比较拟合表现和阈值距离，不作为唯一主模型。

# 2. 题目任务拆解

题目第二问要求：

1.  联合考虑声谱图相关性、幅度谱相关性、幅度包络相关性，构造随传播距离变化的声学保真度；
2.  分别建立 flat、mod、tv 三种叫声的传播退化模型；
3.  设计分级识别阈值，至少包括：
    -   潜在识别的最低相似度；
    -   一般识别；
    -   更严格的可靠识别；
4.  重点计算潜在识别和可靠识别两种标准下的有效通信距离；
5.  给出距离不确定性区间并进行敏感性分析；
6.  比较三种叫声的远距离传播鲁棒性。

题目第四问举例提出将识别相关性阈值从 0.5 提高到 0.6 或
0.7。因此，本方案将 0.5、0.6、0.7
作为可解释的**操作性阈值方案**，但不能声称它们已经由企鹅听觉实验标定为真实生物学边界。

# 4. 物理传播模型

## 4.1 传播损失

建议采用频率相关的传播损失表达式：

\[
TL(f,d)=10n`\log`{=tex}*{10}`\left`{=tex}(`\frac{d}{d_0}`{=tex}`\right`{=tex})
+`\alpha`{=tex}*{`\mathrm{air}`{=tex}}(f)(d-d_0)
+L\_{`\mathrm{mp}`{=tex}}(f,d) \]

其中：

-   (d)：传播距离；
-   (d_0)：参考距离，传播公式可取 1m；
-   (n)：几何扩散系数；
-   (`\alpha`{=tex}\_{`\mathrm{air}`{=tex}}(f))：频率相关的空气吸收系数，单位需统一为
    dB/m；
-   (L\_{`\mathrm{mp}`{=tex}}(f,d))：海面反射、多径干涉等附加损失。

解释：

-   (n=2) 对应球面扩散的基准情形；
-   (n=1) 可作为柱面扩散极限的敏感性情景；
-   对本题近海面空气传播，建议先以 (n=2)
    为基准，再在合理范围内进行敏感性分析；
-   不得把水下声呐传播公式直接套用于企鹅在海面上方的空气声传播。

如果没有海面几何和反射参数，不要声称已准确模拟多径。可将
(L\_{`\mathrm{mp}`{=tex}})
设为可选模块或有效残差项，并清楚标注为情景假设。

## 4.2 频率响应与接收信号

传播信道的压力传递函数可写为：

\[ H(f,d)=10\^{-TL(f,d)/20}M(f,d) \]

其中 (M(f,d)) 表示复数形式的多径/干涉效应。

更具体的直达声加反射声形式可作为扩展：

\[ H(f,d)=H\_{`\mathrm{direct}`{=tex}}(f,d)
+`\Gamma`{=tex}(f,`\theta`{=tex})H\_{`\mathrm{reflected}`{=tex}}(f,d) \]

(`\Gamma`{=tex})
为表面反射系数。若缺少反射路径长度、入射角和表面状态，不得自由拟合所有多径参数；应固定或设置情景范围。

接收信号：

\[ Y_c(f,d)=X_c(f)H(f,d)+N(f,d) \]

其中 (X_c(f)) 为叫声类别 (c) 的声源频谱，(N(f,d)) 为环境噪声。

## 4.3 接收信噪比

可用下式表示接收信号的积分信噪比：

\[ SNR_c(d)= `\frac{\int |X_c(f)|^2|H(f,d)|^2\,df}`{=tex}
{`\int `{=tex}S_N(f,d),df} \]

其中 (S_N(f,d)) 为噪声功率谱密度。

物理解释：

-   三种叫声的源频谱不同；
-   空气吸收具有频率选择性；
-   环境噪声具有频谱结构；
-   因此即使处于相同传播距离，三种叫声也可能有不同的接收 SNR。

**数据限制：** 九份 CSV
只有相关性，没有绝对声源声压级、噪声功率谱、温湿度、风速和海面几何。因此不能仅凭九份
CSV 独立识别全部物理参数。

建议采用以下处理：

1.  若 Supplementary 5
    音频可用，提取三种叫声的代表性功率谱/包络，作为相对声源频谱模板；
2.  绝对声源级和噪声级若不可得，使用 4m 处的有效 SNR
    作为待估校准参数，而不是虚构绝对声压；
3.  空气吸收系数需要温度、湿度等参数；没有实测值时，使用有来源的标准参数或范围作情景分析；
4.  几何扩散、空气吸收和噪声不能全部自由拟合，否则会出现参数不可辨识。

# 5. 物理机制与相关性指标之间的连接

## 5.1 加性噪声下的理论关系

在简化模型：

\[ y(t)=x(t)+n(t) \]

且 (x,n) 不相关时：

\[ `\rho`{=tex}=`\operatorname{Corr}`{=tex}(x,y)
=`\frac{1}{\sqrt{1+1/SNR}}`{=tex} =`\sqrt{\frac{SNR}{1+SNR}}`{=tex} \]

该式说明：信噪比越高，原始信号与接收信号的相关性越接近 1。

但必须注意：CSV
中的三个相关性是声谱图、幅度谱、包络等特征域相关性，并非都等价于原始波形
Pearson
相关系数。因此该公式只能作为理论桥梁，不能不加验证地当作三个观测指标的精确生成公式。

## 5.2 推荐的半机理观测模型

建议先实现以下可解释候选模型：

\[ `\mu`{=tex}*{m,c}(d)= q*{m,c}(d)
`\sqrt{\frac{SNR_c(d)}{1+SNR_c(d)}}`{=tex} \]

其中：

-   (m`\in`{=tex}{s,a,e})，分别代表声谱图、幅度谱、幅度包络；
-   (c`\in`{=tex}{flat,mod,tv})；
-   (q\_{m,c}(d)`\in`{=tex}(0,1\]) 为结构保留因子；
-   (SNR_c(d)) 由传播损失和噪声模型决定。

(q\_{m,c}(d))
用来表示加性噪声关系无法解释的特征结构畸变，例如频率选择性失真、多径时间展宽和时频结构改变。

建议先用低维、可解释的形式作为候选：

\[ q\_{m,c}(d)=`\exp[-\kappa_{m,c}(d-d_0)]`{=tex}\]

(`\kappa`{=tex}\_{m,c}`\geq0`{=tex}) 是有效结构退化系数，单位为
m(\^{-1})。该参数是对未显式建模结构畸变的有效修正，不应直接称为某个已测得的海面物理常数。

如果有足够音频和传播几何信息，优先尝试"声源音频 + 传播信道 +
噪声"的前向模拟，直接计算三种特征相关性；此时可减少或替代自由的 (q)
参数。

## 5.3 估计方法

相关性观测值位于 (0,1)，可尝试：

-   Beta 似然：以 (`\mu`{=tex}\_{m,c}(d)) 为均值、精度参数为
    (`\phi`{=tex})；
-   Fisher-z 变换后的回归作为对照；
-   采用共享环境参数、叫声特异的声源频谱和有限数量的结构退化参数；
-   参数需有物理约束，例如 (n)
    的范围、(`\kappa`{=tex}`\geq0`{=tex})、(q`\in`{=tex}(0,1\])。

重点检查参数可辨识性。若几何扩散、空气吸收、噪声级和结构退化系数高度混淆，应固定一部分参数或改用情景范围，不能为了拟合好看而增加自由参数。

# 6. 综合声学保真度模型

## 6.1 基准方案：等权算术平均

\[ F_c(d)=`\frac{
\mu_{s,c}(d)+\mu_{a,c}(d)+\mu_{e,c}(d)
}{3}`{=tex} \]

理由：

-   三种相关性量纲和范围一致；
-   题目要求联合考虑三种指标，但未给出可靠的生态权重；
-   等权重透明、易复现，适合作为基准。

如果行级配对关系经验证成立，可先计算每条观测的综合值：

\[ F\_{c,j}(d)=`\frac{R_{s,c,j}(d)+R_{a,c,j}(d)+R_{e,c,j}(d)}{3}`{=tex}
\]

如果不能确认行级配对，则只在距离层面融合三个指标的预测均值，不得按行强行相加。

## 6.2 敏感性方案：几何平均

\[ F\_{c,`\mathrm{geo}`{=tex}}(d)= `\left[
\mu_{s,c}(d)\mu_{a,c}(d)\mu_{e,c}(d)
\right]`{=tex}\^{1/3} \]

几何平均会降低"某一指标很高而另一指标很低"时的补偿效应。它不是天然正确的唯一选择，应与算术平均比较通信距离和类别排序是否稳定。

不建议在缺少识别标签的情况下用机器学习任意训练三个权重。

# 7. 分级识别阈值模型

## 7.1 阈值设置

采用以下操作性分级：

  状态             综合保真度
  ---------------- --------------------------
  未达到潜在识别   (F\<0.5)
  潜在识别         (0.5`\leq `{=tex}F\<0.6)
  一般识别         (0.6`\leq `{=tex}F\<0.7)
  可靠识别         (F`\geq0.7`{=tex})

重点距离：

\[ D_c(0.5):`\text{潜在识别距离}`{=tex} \]

\[ D_c(0.7):`\text{可靠识别距离}`{=tex} \]

0.6 用于中间等级和敏感性分析。

**重要说明：** 0.5、0.6、0.7 是题目情景和本方案提出的操作性阈值，不是由
Data03--11 训练得到的企鹅真实心理声学识别阈值。需要在报告中明确这一点。

## 7.2 阈值与等效 SNR 的联系

在理想的 (q=1) 加性噪声模型下：

\[ SNR_T=`\frac{T^2}{1-T^2}`{=tex} \]

    相关性阈值 T   等效线性 SNR   等效 SNR (dB)
  -------------- -------------- ---------------
             0.5          0.333        -4.77 dB
             0.6          0.563        -2.50 dB
             0.7          0.961        -0.17 dB

如果存在结构保留因子 (q)，则：

\[ SNR_T= `\frac{(T/q)^2}{1-(T/q)^2}`{=tex},`\quad `{=tex}q\>T \]

若 (q`\leq `{=tex}T)，该结构保留水平下即使没有额外噪声，也无法达到阈值。

以上是简化信号模型中的等效 SNR 解释，不代表企鹅的真实听觉心理声学阈值。

## 7.3 有效通信距离定义

对每种叫声和阈值 (T)，求：

\[ D_c(T)=`\inf`{=tex}{d`\geq4`{=tex}:`\hat `{=tex}F_c(d)\<T} \]

采用从近距离向远距离的**首次向下穿越**作为保守有效距离，避免局部反弹把通信距离高估。

边界情况：

-   256m 仍高于阈值：报告"有效距离至少达到 256m"，不得无依据外推；
-   4m 已低于阈值：报告"有效距离小于 4m"；
-   若物理多径模型出现多个穿越点，应同时展示完整曲线，并将首次向下穿越作为保守指标。

# 8. 非单调、缺失与异常数据的处理规范

1.  保留所有合法原始观测，不为了获得单调曲线而删除数据。
2.  NA 不填 0，不做均值填充。
3.  对每个距离计算均值、中位数、标准差、四分位距、有效样本量。
4.  IQR/MAD 只用于标记异常候选；只有能证明是录入或测量错误时才剔除。
5.  物理模型可产生总体衰减趋势，但海面反射/多径可能造成局部起伏，不应把"每个点必须严格下降"作为原始数据清洗条件。
6.  原作者 GAM
    复现作为基准；单调保序回归可作为敏感性对照，不作为唯一主模型。
7.  不要把七个距离的均值直接线性插值作为最终距离模型。

-   生成缺失统计、分布图和描述统计；
-   核实三个指标的行号是否对应同一观测对象。

## 9.2 建立模型

至少比较三种模型：

A. 原作者 GAM 基准模型：

\[ R(d)=s(`\log`{=tex}\_2d) \]

B. 物理 SNR 模型：

\[ `\mu`{=tex}(d)=`\sqrt{\frac{SNR(d)}{1+SNR(d)}}`{=tex} \]

C. 推荐半机理模型：

\[ `\mu`{=tex}*{m,c}(d)=q*{m,c}(d)
`\sqrt{\frac{SNR_c(d)}{1+SNR_c(d)}}`{=tex} \]

比较拟合误差、残差结构、参数稳定性和阈值距离，不要只比较训练集拟合优度。

## 9.3 Bootstrap

-   在每个叫声、每个距离内重抽样有效观测；
-   若三指标行级配对已确认，对三指标使用相同抽样索引，保留指标间相关性；
-   若未确认配对，不得强行联合抽样；
-   每次重拟合模型、重新计算综合保真度和阈值交点；
-   重复足够次数，给出有效距离的 95% 区间；
-   如果原始数据没有录音/播放试次 ID，普通行级 Bootstrap
    只能视为近似，需说明观测可能存在共享录音导致的相关性。

## 9.4 敏感性分析

至少包括：

-   阈值：0.5、0.6、0.7；
-   融合方式：算术平均、几何平均；
-   几何扩散系数：基准 (n=2)，并对合理范围（例如 1--2）作情景检验；
-   环境噪声：基准及增加 5dB、10dB 等明确标注的情景；
-   空气吸收：按频率和环境参数范围进行情景检验；
-   多径：无多径基准与合理反射情景；
-   结构退化参数：估计值及其区间。

不要把情景参数写成数据实测值。

## 9.5 Data02 的辅助验证

可用 Data02
检查模型预测保真度与行为响应是否具有合理关联，例如对抬头、鸣叫、靠近分别建立行为概率模型。

但需要控制 Context、CallType、Distance、Npenguins
等因素；行为响应不能等同于听觉识别成功。该部分属于辅助生态验证，不取代第二问的传播模型。

# 11. 必须向项目组明确的限制

1.  九份 CSV 是相关性数据，不是绝对声压、声源级、噪声谱或完整接收波形。
2.  仅靠这些
    CSV，无法同时唯一确定几何扩散、空气吸收、海面反射、环境噪声和结构畸变参数。
3.  需要固定/约束一部分参数，并对缺少的环境信息进行情景分析。
4.  相关性不等于能量，也不等于真实识别概率。
5.  0.5、0.6、0.7 是题目启发的操作性阈值，需要明确其假设性质。
6.  Data02 行为响应可辅助验证生态合理性，但无响应不等于未感知。
7.  创新点应表述为"将物理传播、特征保真度和分级识别距离统一到可解释的半机理框架"，不要夸大为已完全识别真实海洋声学传播机制。

# 12. 给 Agent 的执行优先级

**第一阶段：数据与可辨识性检查**

先完成九份 CSV
的审计、行级对应关系核验、音频文件可用性检查。不要立即拟合复杂模型。

**第二阶段：基准模型**

复现原作者 GAM；同时建立简单 SNR
衰减基准，确保预处理和阈值求解流程正确。

**第三阶段：半机理主模型**

建立几何扩散 + 频率相关空气吸收 + 有效 SNR +
结构保留因子模型。先控制参数数量，检查可辨识性，再逐步增加多径模块。

**第四阶段：阈值与距离**

计算 0.5、0.6、0.7 三个阈值下的距离，重点报告 0.5 和 0.7，并通过
Bootstrap 给出不确定性区间。

**第五阶段：情景分析与交付**

完成环境噪声、扩散参数、空气吸收、多径和融合方式的敏感性分析；交付全部代码、表格、图和模型说明。

**不要在第一阶段就把所有物理参数都放进优化器。先检查数据到底能识别哪些参数，再决定模型复杂度。**
