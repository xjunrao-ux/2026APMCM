# 两版对照、可借鉴内容与勘误

下文以 **A 版** 指前一版 `APMCM_C_Q1_Full`，以 **B 版** 指用户提供的 `2026APMCM_C_P1`。本次复核原始字段、已算结果和报告口径，没有重训 B 版的全部分类对照，也没有开展后续题的正式建模。

## 共同点与互补之处

| 部分 | 两版一致的结论 | A 版的长处 | B 版可借鉴的内容 |
|---|---|---|---|
| 数据与描述统计 | 三类样本数为 44／40／24。F01 中位数依次约 298、287、274.5 Hz。Fpeak 差异最突出，时长和 Q75 的组间区分有限 | 按有效样本计算，逐指标雨云图完整，含 SVG 与 PDF。保留清洗表和缺失审计 | 题面与原始附件、三条示例音频、CV 与派生指标。Fpeak 直方图和峰位比例更容易解释分布差异 |
| 分类 | F02 先分流 24 条双声型，再用脉冲率测值识别 34 条调制型，余下 50 条最难。脉冲率实测值加到 Fpeak 上没有找回剩余 6 条调制型 | 按日期和地点留出整批、堆叠内层也分批，提供折外逐条结果和可运行分类器 | 规则顺序的反例、只用连续特征的多项逻辑回归、逐条留一和 AUC 对照。可借来解释规则的简洁性和用途 |
| 非参数检验 | KWH 原始统计量一致。Fpeak 的平直型–调制型两两差异稳健。实测脉冲率 MWU 为 0.2785。PERMANOVA 伪 F 约 2.688，R² 约 4.87% | 对七项检验用 Holm；增加日期与地点分块置换、剔除 Fpeak、Anderson–Darling 等对照 | 对六项 KWH 用 BH；补充效应量森林图、PCoA、曼哈顿距离与 PC1–PC2 敏感性，以及假设下的脉冲率检验力 |
| 传播与回放 | 128 m 时频图保真顺序为双声型、调制型、平直型。自然声比海浪声更常引发回应 | 三通道距离曲线和按鸣声类型分解的抬头、鸣叫、靠近计数可以直接支持功能讨论 | 三条示例声谱与包络、八种行为组合以及距离近似匹配子集，增强结构解释并为行为建模提供诊断 |
| 后续指标 | 保留类型、距离、频率与调制结构信息。正式衰减与行为模型留给后续 | 区分当前可直接使用的变量与需逐轨提取的指标 | 将峰位比、包络和双基频特征联系起来，适合作机制假设和备选特征 |

数据复核按行比较了 Data01、Data02 的共同字段，日期按日/月/年标准化后相同。将 A 版传播长表按来源文件和原表行号还原后，九张原始矩阵的数值及缺失位置均相同。因此两版是在同一批数据上的交叉核对。[数据核对表](tables/source_equivalence.csv) · [B 版数据说明](../2026APMCM_C_P1/01_数据/数据说明.md) · [A 版数据说明](../APMCM_C_Q1_Full/data/README.md)

## 数字为什么有差异

### 显著性

| 指标 | 原始 p | A 版 Holm（6 项 KWH＋1 项脉冲率 MWU） | B 版 BH（6 项 KWH） |
|---|---:|---:|---:|
| Fpeak | 0.00216 | **0.01512** | **0.01296** |
| F01 | 0.01034 | 0.06201 | **0.03101** |
| Q50 | 0.04025 | 0.20124 | 0.08050 |

BH 控制错误发现率，Holm 控制检验族内至少一次假阳性的概率，两个分析的检验数也不同。正文采用已设定的七项 Holm 主口径。F01 报告为有差异迹象，并并列说明其在 BH 和分块秩置换下通过阈值。两版的 PERMANOVA 分别使用 49,999 和 9,999 次置换，整体 p 分别为 0.00788 和 0.0081，伪 F 和 R² 一致。PERMDISP 两版都未检出离散度差异，仍需保留有限样本下的不确定性。[校正对照表](tables/adjustment_comparison.csv) · [A 版统计报告](../APMCM_C_Q1_Full/03_nonparametric/report.md) · [B 版统计报告](../2026APMCM_C_P1/04_报告/03_非参数检验.md)

### 分类

| 比较 | 用同一口径解读 |
|---|---|
| 94.4% 规则基线与 94.4% 堆叠 | B 版规则和 A 版规则基线为同一方案。规则判对 44 条平直型、34 条调制型、24 条双声型。A 版 50 条训练的堆叠改为 41、37、24 条正确，整体准确率相同。平直型召回从 100% 变为 93.2%，调制型召回从 85.0% 变为 92.5% |
| Fpeak 的 AUC 0.705 与 0.690 | 0.705 是在 84 条上按较低原始 Fpeak 更像调制型来排序的样本内 AUC。0.690 是 A 版分批留出的模型折外 AUC。两者反映不同评估方式 |
| 六指标与脉冲率组合的 AUC | B 版逐条留一，手写逻辑回归。其 AUC 脚本中部分“加脉冲率”的行实际输入 `hasPR`，意味着加入测值指示。A 版按批次留出，将指示项和实测项拆开评估。AUC 不宜据此跨协议直接排名 |
| 84 条分类与实际第三层 | 84 条包含已被第二层分流的 34 条调制型。第三层只有 44 条平直型和 6 条调制型，须另外给出找回和误报计数 |

日期与地点分批更贴近对新录音批次的验证需求。正文可把两条规则作为简明基线，并报告堆叠第三层的召回权衡。B 版多项 logit 和配对 bootstrap 图可放补充材料，标注逐条留一与样本级重采样。由于缺少企鹅个体编号，两版均未验证新个体表现。[A 版分类报告](../APMCM_C_Q1_Full/02_classification/report.md) · [B 版分类报告](../2026APMCM_C_P1/04_报告/02_影响因素与分类器.md) · [原始特征 AUC 方向核对](tables/raw_feature_auc_direction.csv)

## 需要修正或降级为假设的表述

| 原表述或数字 | 核对结果与合并写法 |
|---|---|
| B 版规则的平直型精确率为 100% | **精确率 88.0%（44/50），召回率 100%（44/44）。** 6 条调制型也被判为平直型 |
| B 版将 `Fpeak/F01 < 2` 的双声型报为 9/24，并把其互补组全算作第三谐波 | 该比值规则实际是 **5/44、15/40、8/24**。绝对频率规则 `Fpeak < 500 Hz` 是 **4/44、15/40、9/24**。两种定义分别报告。比值不低于 2 的样本可处在多个谐波区间，主文采用“低频峰比例”或“峰位比”措辞 |
| B 版 F01 的“方向修正后 AUC”为 0.427 | 原始 F01 值越高越像调制型时为 0.427，采用与样本趋势一致的低值方向时为 **0.573** |
| B 版二元特征 5,000 次置换给出 p<0.0001 | 该脚本用 `count/5000`，零次超越会打印 0.0000。按加一修正，零次超越时约 **0.0002**。综合报告直接使用观察到的比例和分类规则 |
| B 版双声型时频图相关 0.70 的对数距离插值约 166 m | 按相邻均值 128 m 的 0.740 和 256 m 的 0.318，复核约 **137 m**。这仅是单通道、未建模的插值。正文使用实测距离区间 |
| B 版称包络的绝对降幅普遍最大 | 以平直型 4–256 m 为例，包络降约 0.481，时频图降约 0.742。合并稿表述为包络相似度较早低于阈值，并分别呈现各通道的曲线 |
| B 版将六条空脉冲率归因为测量失败、将双声联系到亲缘或配偶识别 | 空值也可能与录音质量、提取口径或其他原因有关。每类只有一条示例音频，缺少与这六条记录匹配的原音及身份实验。合并稿以“待验证机制”描述 |
| 传播矩阵中每行被称为一条独立录音 | 实验以多个录音组合产生相关值，矩阵行号可供溯源，跨通道缺失位置相同仍需校验实际配对键。正式模型要保留依赖结构 |
| 仅从文件名或三位编码合并行为组合 | 两版组合位序不同。A 版为“抬头、鸣叫、靠近”，B 版组合表为“抬头、靠近、发声”。同一实验的 90 对距离不同，另有两对群体大小不同。联表以三项命名字段和每次回放的协变量为准 |
