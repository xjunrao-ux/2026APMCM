# APMCM C 题第一问｜三层叫声分类器

固定阈值 0.50 的三层方案找回 **6 条脉冲率为空的调制型中的 3 条**，同时把 3 条平直型误判为调制型。整个分类器判对 **102/108 条（94.4%）**，与双规则基线准确率相同。调制型召回率从 **85.0%** 提高到 **92.5%**，平直型召回率从 **100%** 降至 **93.2%**。

## 分类流程

1. **第二基频。** `F02` 有合法测值，判为双声型 `tv`。空值进入第二层。Data01 有 24 条在这一层分类。
2. **脉冲率。** `PulseRate` 有合法测值，判为调制型 `mod`。空值进入第三层。Data01 有 34 条在这一层分类。
3. **六指标堆叠逻辑回归。** 输入为时长 `Duration`、第一基频 `F01`、峰值频率 `Fpeak` 和频谱分位频率 `Q25`、`Q50`、`Q75`。第三层的数据是双空值的 50 条样本，其中 44 条 `flat` 和 6 条 `mod`。脉冲率始终保留为空。

第三层先训练两个二元 L2 逻辑回归。一个接收时长，另一个接收五项频率指标。随后用两个模型对 `mod` 的折外分数再训练一个二元 L2 逻辑回归。各模型固定 `C=1`，使用平衡类别权重，标准化参数只在相应的拟合折估计。最终输出的是带类别权重模型的分类分数。

主评估按日期和地点划分 16 个采集批次，每次留出一批测试。其中 11 个批次含第三层样本。在每个外层训练集中，再按批次留出，生成用于拟合上层回归的基模型折外分数。额外评估了训练集内选阈值的版本，使用独立于元模型拟合分数的整套堆叠折外分数，在 0.50 至 1.00 中选择准确率最高的阈值，同分时优先找回较多的 `mod`。

## 验证结果

| 第三层做法 | 找回空值 mod | 误报 flat | 第三层准确率 | 三层准确率 |
|---|---:|---:|---:|---:|
| 全判 flat，双规则基线 | 0/6 | 0/44 | 44/50（88.0%） | 102/108（94.4%） |
| 单个六指标逻辑回归，阈值 0.50 | 1/6 | 13/44 | 32/50（64.0%） | 90/108（83.3%） |
| 堆叠逻辑回归，阈值 0.50 | 3/6 | 3/44 | 44/50（88.0%） | 102/108（94.4%） |
| 堆叠逻辑回归，训练集内按准确率选阈值 | 0/6 | 0/44 | 44/50（88.0%） | 102/108（94.4%） |

固定 0.50 时的逐类折外结果如下。

| 真实类别 | 判为 flat | 判为 mod | 判为 tv |
|---|---:|---:|---:|
| flat | 41 | 3 | 0 |
| mod | 3 | 37 | 0 |
| tv | 0 | 0 | 24 |

|---:|---|---:|---|
| 10 | 2021-07-16 | 0.554 | mod |

固定阈值下，另外 3 条 `flat` 被误报为 `mod`，原表行号为 42、53、78。未找回的 3 条 `mod` 来自同一批次，该批次留出时第三层训练集只有 3 条 `mod`。这项实验复核的是 Data01 的类别和现有测量记录。原始空值的脉冲率数值仍未观测；前三层的结果也未在新录音上单独验证。

## 复现和预测

```bash
python -m pip install -r requirements.txt
python three_stage.py train
python three_stage.py predict features.csv --output predictions.csv
```

预测表需要列 `F02`、`PulseRate`，以及第三层样本对应的六个实测指标。默认阈值为 0.50，以保留本实验观察到的召回增益。对第二基频或脉冲率测量流程不同的新录音，需要检验前两层的适用性。

- `results/models.joblib` 为用全部 50 条第三层样本拟合的模型和默认阈值。
- `results/oof_predictions.csv` 为 108 条样本的折外预测与所走分支。
- `results/unmeasured_pulse_mod.csv` 为六条脉冲率为空的 `mod` 的折外明细。
- `results/metrics.csv` 为各方案的比较指标。

Data01 为比赛数据的预处理版本，原数据由 [Thiebault 等](https://doi.org/10.5281/zenodo.21376648) 发布，许可为 CC BY 4.0。
