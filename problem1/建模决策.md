# 第一问建模决策

**研究对象。** 观测单位为一条有人工类别标签的海面叫声。估计目标是给来自另一录音日的叫声分类，同时找出有声学解释的类别差异。题面依据为英文 C 题第 2 页，字段定义见第 7 页。执行次序依交接稿第 11 节。

| 顺序 | 核对依据 | 决策 |
|---|---|---|
| 1　读取 | Data01 实有 108 行、11 列，flat 44、mod 40、tv 24 | 按日/月/年解析日期，保留原 CSV 行号和类型标签 |
| 2　质量 | 六项共性指标无缺失，物理约束和重复检查均通过。多个规则合计标记 46 条可能极端记录 | 保留全部观测。F02 只描述 tv，PulseRate 只比较有观测的 mod 与 tv。无个体编号，用日期刻画同批风险 |
| 3　描述 | 按类核对分布、中位数、IQR、Pearson、Spearman 与 VIF。最高 VIF 约 2.35 | 保留原量纲进行描述。用共同分箱比较直方图，以箱线图和散点图识别重叠 |
| 4　检验 | 对六特征做 Kruskal–Wallis，对每项的三组配对做双侧 Mann–Whitney U。按六个总体假设和十八个两两假设分别 Holm 校正，脉冲率为单独的事先指定比较 | α = 0.05。总体效应量取秩 epsilon² = H/(N−1)，两两报告 Cliff’s δ = 2U/(n₁n₂)−1，正值表示前一类倾向更高。另在日期内随机重排标签 4,999 次检验总体差异，六项一起做 Holm 校正 |
| 5　固定输入 | 六项共性特征均可在未知类别时测量。峰值频率总体差异最清楚，单变量显著性无法规定多变量的预测价值 | 固定 Duration、F01、Fpeak、Q25、Q50、Q75。日期仅分组；地点、F02、PulseRate 及其缺失标记均不参与预测 |
| 6　主模型 | 三类无序，小样本，需解释同一特征对类别相对优势的贡献 | 各训练折内 Z 标准化，采用带 L2 惩罚的多项逻辑回归；无插补、重采样或有监督筛选。保留原始观测权重，单独报告 tv 召回 |
| 7　对照模型 | 六项指标可能存在非线性组合 | 用相同输入和划分比较 RBF-SVM 与随机森林。SVM 折内标准化，森林用原尺度。内层按 Macro-F1 选参，参数网格见 results/model_config.json |
| 8　验证解释 | 16 个日期，每日类别组成有差异 | 外层 5 折、内层 3 折，各层均按日期分组并要求三类齐全。另作普通分层嵌套对照。汇总折外预测计算主指标，另列折间波动。全量重拟合仅用于解释与交付。对标准化特征用类别系数差解释相对 flat 的优势比 |
| 9　实验衔接 | Data02 有播放试次和反应，Data03–11 为相对 1 m 的传播相关，Data01 无跨表唯一键 | 比较同一类别的声学画像、各距离三项保真度和各行为响应率。后续模型按类别或实验条件对接。对行为功能只提出数据支持的假设 |

日期内置换保留每天的标签计数，以保持该日的类别组成。该敏感性分析依赖日内可交换性。缺少个体标识，同一只企鹅被多次采样的影响仍可能存在。协变量之间共享信息，正则化系数用于条件关联解释。
