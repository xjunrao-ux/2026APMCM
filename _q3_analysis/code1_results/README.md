# 亚太赛 C 题第三问第二小问｜Code1 复核数值表

本包汇总 Code1 对八类行为组合主分析的复核。配套 Markdown 说明方法、主要发现与论文表述。

| 文件 | 记录数 | 内容 |
| --- | ---: | --- |
| `Q3_2_Code1_All_Contrasts.csv` | 56 | 自然鸣声等权总体对照 8 项、三类鸣声各自对照 24 项、三类鸣声两两比较 24 项。含两侧的调整概率、概率差，以及按录音轨道和按实验编号重抽样的两套同时 95% 置信区间。 |
| `Q3_2_Code1_Model_Sensitivity.csv` | 32 | 原模型、加入播放前鸣叫次数、加入完整情境与鸣声交互、两者均加入，每个设定给出八种组合的预测概率、概率差和按自然录音轨道划分的五折交叉验证对数损失。 |
| `Q3_2_Code1_Context_Counts.csv` | 48 | 三种情境与两类播放组下八种组合的原始频数、全部播放分母和已响应播放分母。 |

- 末尾为 `_pct` 的列单位为百分比，末尾为 `_pp` 的列单位为百分点。概率差计算为 `stimulus` 减 `reference`。
- `natural_equal` 为 flat、mod、tv 的调整概率等权平均。`natural_observed` 为实测自然声播放按原样本直接合计。
- `H`、`V`、`A` 分别表示抬头、鸣叫和靠近。`No response` 表示三种行为均未出现，对应的「已响应播放占比」留空。
- 轨道区间由按鸣声类型分层、在每类中按轨道整组重抽样 3,000 次得到。同一轨道涉及的试验与配对对照整组保留。三个比较族分别计算同时区间。`track_interval_excludes_zero` 表示该区间是否排除零。
- 交叉验证对数损失按模型规格计算，在该规格的八行中重复显示。CSV 采用 UTF-8 BOM 编码。
