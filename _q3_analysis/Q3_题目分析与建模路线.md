## 1. 题面逐句拆解：它到底要几个东西

| 题面原句 | 要的产出 | 隐含的统计要求 |
|---|---|---|
| 比较对自然鸣声回放与对照声音回放的**总体响应率** | 一个 2 组对比（自然 vs 对照）的响应率差 | 要效应量 + 区间，不只是 p 值；配对面必须处理 |
| 分析响应差异与 **Context、CallType、Distance、Npenguins** 的关系 | 四因素的主效应/交互效应表 | 距离是非线性；群体规模是"至少一只"口径 |
| 将**抬头、鸣叫、靠近**视为三种响应行为 | 三条行为各自的响应模型 | 不能合并成一个 ResponseYesNo |
| 分析单次刺激后**响应行为组合的概率分布** | 8 格（2³）概率分布图 + 两组差异检验 | 稀疏列联表；组合受归一化约束，不能拆成 8 个独立 logit |
| 在**统一建模框架**内比较自然声与对照，评估 CallType 是否提高**特定组合**的概率 | 一个模型内的刺激因子 + 交互 + 组合层面的边际效应 | 明确禁止"两个模型各跑一遍再目测" |
| 对 VocalNcalls / HeadsUpDuration / ApproachDuration 等强度指标建立**响应潜伏期模型** | 时间-事件模型 + 强度模型 | 无响应 = 右删失；强度只在响应时定义（零膨胀/障碍） |
| 给**代表性条件**下的预测数值表（Np=中位数；50/100/150 m；各鸣声类型） | 一张 4×3 的预测表 | 每格要 p、时延、区间；条件时延与无条件时延要分开 |
| "无响应"不等于"未感知" | 模型结构层面的解释 | 两段式：感知 × 决策 |

**结论：题面要求 6 项可交付物，不是 3 个。**（它是"总率—四因素—三行为—组合—时延—预测表"六层，逐层加结构。）

## 3. 由此决定的四个建模障碍

1. **伪重复 + 配对断裂**：随机效应要有两层（实验、刺激录音），配对要靠条件 logistic 或距离校正；两条都要做，否则第二问的"关系"会被设计缺陷污染。
2. **群体口径 vs 个体口径**：数据是"观察到的群体里有没有出现行为"，天然饱和于 N。必须显式写
   $$p_{\text{group}}=1-(1-p_{\text{ind}})^{N}$$
   这是把"鸟多就容易有响应"从混杂变成结构的唯一干净办法（见 §4.2）。
3. **删失 + 零膨胀**：时延有右删失，强度只在响应时定义。任何把"未响应"当 0 或当缺失的做法都会毁掉第四句。
4. **稀疏**：靠近只有 23/278 次。四因素全交互在本样本量下不可估 → 模型集必须预先定小、靠部分合并/正则化先验。

### 部分 1　总体响应率（基准层）

**问题**：自然鸣声回放的响应率比对照高多少？（不校正，先给一个可被非专业读者引用的数）

**模型/方法**

| 分析 | 方法 | 说明 |
|---|---|---|
| 粗率 | 4 个刺激水平的响应率 + Wilson 95% CI | 分母写清是"每次回放"（278）还是"每个实验"（139） |
| 配对比 | **McNemar**（139 对，b/c 不一致对） | 只作为"忽略距离"的对照 |
| 主分析 | **条件 logistic**（按 expID 分层，含 log d） | 距离不同也能估，且自动利用配对 |
| 效应量 | RD、RR、OR（bootstrap 或后验区间） | 三套都给，别只给 OR |

**关键论证**：McNemar 与条件 logit 的差 = 配对内距离不平衡造成的偏倚量。这一句就把"设计缺陷"变成"稳健性证据"。

**坑**：作者原代码 `sum(HeadsUpYesNo)/length(unique(expID))` 用 139 作分母、分子却是 278 行之和，会得到约双倍的值。**别照抄**；分母口径要在正文声明。

### 部分 2　四因素响应模型（解释层）

**问题**：控制其他因素后，刺激类型、情境、距离、群体规模各自把响应概率改变多少？距离的衰减形状是什么？

**主模型**：分层贝叶斯二项 GLM，**cloglog 连接 + log N 作 offset**

$$\operatorname{cloglog}\big(p_{\text{group},i}\big)=\log N_i+\alpha+\beta_{s(i)}+c_{\text{ctx}(i)}+g(\log d_i)+u_{\text{exp}(i)}+v_{\text{track}(i)}$$

为什么是 cloglog：
$$p_{\text{group}}=1-(1-p_{\text{ind}})^{N}\iff \log\big[-\log(1-p_{\text{group}})\big]=\log N+\log\big[-\log(1-p_{\text{ind}})\big]$$
这是**恒等式**，不是近似。于是系数直接读作**个体级**响应概率的对数风险比，P4 要的 $p_{\text{ind}}$ 直接拿到手。

**结构假设的检验**：把 log N 的系数放开估计。若 ≈1 → 独立同质个体成立；若 <1 → 个体异质（frailty），此时报"有效个体数"并说明饱和更慢。这个检验本身就是一段可写的分析。

**距离项**：$g(\log d)$ 用 3 结点样条或二次式；与"用 P2 的 $F_k(d)$ 替代 d"的两版并列，后者给出心理测量函数
$$p_{\text{rec}}(d)=\sigma\big((F_k(d)-T)/s\big)$$
—— 这一版是把 P2 接进 P3 的钩子，也是一张很漂亮的"响应率 vs 保真度"图。

**备选/对照**：logit + log N 自由斜率；GEE（稳健方差，按 expID 聚类）作为频率学派旁证。

**交互**：只放 `刺激 × log d` 与 `Context × 刺激`（预先指定），其余靠 LOO/WAIC 判断，不做全交互搜索。

**产出**：OR/HR 森林图、距离-响应曲线（按 4 水平）、N-响应曲线、LOO 比较表、后验预测检验图。

### 部分 3　8 种组合的联合分布（结构层）

**问题**：一次回放之后，(抬头, 鸣叫, 靠近) 的联合分布长什么样？自然声是否改变了这个分布，而不只是抬高了某个边际？哪种鸣声类型抬高了哪一种组合？

**三步**

1. **描述与整体检验**：8 格概率（自然 vs 对照并列）；整体齐性用 $\chi^2/G$，但对照组只有 3 格非空 → 用**置换检验**或把稀有格合并（none / H± / V± / A）后再检验。合并只用于检验，不用于估计。
2. **主模型：多项 logit（8 类，baseline = 全无）**
   $$\log\frac{\pi_{ic}}{\pi_{i0}}=\alpha_c+\beta_c^\top x_i,\quad c=1..7$$
   直接给"某组合的概率被某刺激抬高多少"（题面原话），并给每格的平均边际概率与 RD，配 FDR。
3. **结构模型：多元 probit**（3 个潜变量 + 相关阵 $\Sigma$）
   $$Z_{ib}=\alpha_b+x_i^\top\beta_b+u_i+\varepsilon_{ib},\quad \varepsilon_i\sim N(0,\Sigma)$$
   它回答多项 logit 答不了的问题：**刺激是否改变了行为之间的耦合**（例如自然声让"抬头→靠近"更连贯）。23 次靠近使 $\Sigma$ 中与 A 相关的元素弱识别 → 用正则化先验（LKJ）并明说。

**可选**：log-linear 模型 / 潜类别（2–3 个"响应综合征"：警觉型、接近型、冷漠型）作为讨论用的探索性附录，明确标注为探索性。

**为什么不能拆成 3 个独立 logit**：三个 0/1 的边际不决定联合分布；题面问的是"组合"，必须是联合模型。

### 部分 4　潜伏期 + 强度（时间层，本题方法学分水岭）

**问题**：不同回放条件下，企鹅**多久**开始响应？响应后**多久/多少次**？

**先解决歧义**：题面"针对鸣叫次数、抬头时长、靠近时长等强度指标，建立响应潜伏期模型"有两种读法（并列两件事 / 以潜伏期为主、强度为辅）。两种都交付最稳：

- **A. 潜伏期**：$T_b$ = 首次出现行为 $b$ 的时刻；未响应 = 右删失于 $W_b$。
- **B. 强度**：给定响应，`VocalNcalls`（计数）、`HeadsUpDuration`、`ApproachDuration`（正连续，含零膨胀）。

| 层 | 主模型 | 备选 | 输出 |
|---|---|---|---|
| 潜伏期 | **AFT**（Weibull / 对数正态），分层 + `(1|expID)+(1|PlaybackTrack)` | Cox + frailty；离散时间 cloglog（若时间精度粗，本数据到 0.1 s，不需要） | 时间比 TR、预测中位时延、生存曲线 |
| 首行为竞争 | 三因竞争风险：cause-specific / **CIF（Aalen–Johansen）** | Fine–Gray 子分布 | "先抬头/先鸣叫/先靠近"的概率曲线 |
| 计数强度 | 障碍负二项（hurdle NB），log N 作 offset | 零膨胀 NB；Poisson 作对照 | 期望鸣叫次数 |
| 时长强度 | 障碍对数正态 / Gamma（log link） | Tweedie | 期望时长 |
| 联合 | 与部分 2/3 共享实验随机效应，构成两段式模型 | — | 一套参数贯穿 |

**为什么 AFT 而不是 Cox**：预测表要的是"中位时延"的绝对数值与区间，AFT 直接给出时间尺度，且能对删失做外推；Cox 只给相对风险。AFT 作主、Cox 作稳健性，正好。

**预测表**（Np = 8，即中位数；4 个刺激 × 3 个距离 = 12 格）

| 刺激 | 距离 | 预测响应概率 (95% CI) | 条件中位时延 s (95% CI) | 无条件中位/受限均值 s | 期望响应个体数 |
|---|---|---|---|---|---|
| flat | 50 | | | | |
| … | | | | | |

**必须同时给两种时延**：
- 条件于响应：$P(T\le t\mid \delta=1)$ 的中位数（好看，但只描述"会响应的那部分"）；
- 无条件：把删失算进去的**受限平均生存时间** RMST$(W)=\int_0^W S(t)\,dt$，或"在 W 内响应的累积概率"。

只报前者是本题最容易被抓的错。若某格 $p_{\text{resp}}$ 很低，"预测时延"应标注为不可靠/不给点估计。

**"无响应≠未感知"的模型化**：写成
$$p_{\text{resp}}=p_{\text{det}}\cdot p_{\text{dec}},\qquad p_{\text{det}}\approx p_{\text{rec}}(d)\ \text{(来自 P2)}$$
$p_{\text{dec}}$ 吸收情境、饱食、群体已响应等。这样"未响应"在模型里有两个来源：没听到（$1-p_{\text{det}}$）与听到但不行动（$1-p_{\text{dec}}$），而不是一句免责声明。

## 5. "统一框架"的正式写法（这是评分点）

一个两段式分层模型，四个部分都是它的不同边际：

$$
\begin{aligned}
&\text{Stage 1（组合）: } && Y_i\in\{0,1\}^3,\quad Z_{ib}=\alpha_b+x_i^\top\beta_b+u_i+\varepsilon_{ib},\ \varepsilon_i\sim N(0,\Sigma)\\
& && Y_{ib}=\mathbb 1\{Z_{ib}>0\}\\
&\text{Stage 2（时延）: } && \log T_{ib}=\mu_b+x_i^\top\gamma_b+w_i+\sigma_b e_{ib},\quad T_{ib}\ \text{在}\ W_b\ \text{处右删失}\\
&\text{共享: } && (u_i,w_i)\sim N(0,\tau^2)\ \text{（实验/录音两层）}
\end{aligned}
$$

- 部分 1 = Stage 1 的边际（$x$ 只留刺激因子）；
- 部分 2 = Stage 1 的各边际（每 $b$ 一个 probit/logit）；
- 部分 3 = Stage 1 的联合（$\Sigma$ 与 8 格概率）；
- 部分 4 = Stage 1 的选择 × Stage 2 的时延；
- 部分 5 = 把 $x$ 代入取预测。

一句话卖点：**"自然 vs 对照"始终是同一个模型里的一个因子，四个问题只是同一后验的四种读出方式。**

## 8. 动手前必须确认的 6 件事

1. **观察窗 $W_b$**：三种行为是否同一窗？数据无字段 → 查视频时长/协议；否则做 60/90/120 s 敏感性。
2. **对照声音是什么**：对照仍有 13/139 抬头、5/139 鸣叫 → 不是静音。若是船噪，"自然 vs 对照"的语义是"生物信号 vs 人为噪声"，解释完全不同。
3. **时延起点**：Latency 是从刺激开始算，还是从首次检测到算？影响绝对数值。
4. **Distance 的测量方式**：目测/激光测距？误差直接进距离项。
5. **`ResponseYesNo` 是否是三者之或**（已确认是）→ 不要单独建模。
6. **编号与分组**：`PlaybackTrack` 29 段是否与 CallType 完全嵌套（是，1|CallType:PlaybackTrack 可简化）。

### 10.3 两个藏在素材里的结论（可直接写进论文）

1. **靠近时长的天花板**：23 次靠近里 **7 次时长正好 60 s**（抬头只有 4/68）。作者的 hurdle NB 把删失当观测值 → 靠近强度被系统性低估。这是我们把靠近时长改成删失/托比特模型的**必要性证据**，不是"换个模型玩玩"。
2. **mod 被播得更近**：中位距离 mod 60 m vs flat/tv/control 80 m；"searching"情境下 mod 50 m vs 80 m。所以 mod 的高响应率（靠近 24%）里有一部分是距离混杂 → 必须靠部分 2 的距离校正拆开，这正好构成"从总率到校正效应"的论证链。
