# APMCM C 题第一问｜第三层使用全部 flat 与 mod 训练

将第三层的训练样本范围扩大到 44 条平直型（`flat`）和 40 条调制型（`mod`）后，六指标和七指标模型的折外表现均未超过上一版。七指标堆叠模型在全部 84 条样本上判对 77 条（91.7%），真正进入第三层的 6 条脉冲率为空的 `mod` 均漏判。

## 模型与验证

第一层依据有无 `F02` 测值识别 `tv`。第二层将剩余样本中有脉冲率测值的记录判为 `mod`。第三层实际接收 50 条样本，其中有 44 条 `flat) 和 6 条脉冲率为空的 `mod`。

- **六指标模型**使用 `Duration`、`F01`、`Fpeak`、`Q25`、`Q50`、`Q75`。
- **七指标模型**加入 `PulseRate`。保留原始空值，使用是否有测值的指示项和仅在有实测值时参与计算的中心化脉冲率项。空值无脉冲率数值贡献。
- **堆叠方案**沿用上一版结构，先分别用时长和频率指标拟合两个逻辑回归，再以两模型的折外分数训练上层逻辑回归。七指标版本将脉冲率两项编码加入频率分支。**单层方案**用同一组指标拟合一个逻辑回归。所有逻辑回归都使用 L2 正则化（`C=1`）、平衡类别权重和固定 0.50 阈值。

外层按采集日期和地点留出一个批次测试，共 16 批。每一折的 84 条训练候选样本先排除当次测试的整批记录。堆叠模型只用训练批次内生成的折外分数拟合上层回归，每次的标准化和脉冲率中心值也只从相应训练数据估计。最后再用全部 84 条训练并保存四个扩充版本。

## 折外结果

84 条一列表示让模型直接预测全部 `flat/mod` 样本。50 条一列表示只检查真正进入第三层的样本。整套准确率同时计入前两层在 Data01 上判对的 58 条。

| 训练范围与模型 | 84 条直接分类 | 第三层判对 | 找回空值 mod | 误报 flat | 三层整体准确率 |
|---|---:|---:|---:|---:|---:|
| 前两层规则，第三层默认 flat | — | 44/50（88.0%） | 0/6 | 0/44 | 102/108（94.4%） |
| 上一版，50 条训练，六指标堆叠 | — | 44/50（88.0%） | 3/6 | 3/44 | 102/108（94.4%） |
| 84 条训练，六指标堆叠 | 29/84（34.5%） | 13/50（26.0%） | 0/6 | 31/44 | 71/108（65.7%） |
| 84 条训练，七指标堆叠 | 77/84（91.7%） | 43/50（86.0%） | 0/6 | 1/44 | 101/108（93.5%） |
| 84 条训练，六指标单层 | 42/84（50.0%） | 26/50（52.0%） | 2/6 | 20/44 | 84/108（77.8%） |
| 84 条训练，七指标单层 | 75/84（89.3%） | 42/50（84.0%） | 0/6 | 2/44 | 100/108（92.6%） |

旧版找回的记录为原表第 10、49、79 条。扩充后的六指标单层回归找回第 10、79 条。两个七指标版均漏掉全部 6 条。第 105、107、108 条来自同一批次，在上述各模型中均漏判。

加入的 34 条 `mod` 都有脉冲率测值，实际已由第二层分走。七指标模型的高分主要发生在包含该组的 84 条直接分类中。进入第三层的样本脉冲率全部为空，因此脉冲率项无法在这 50 条之间提供差异。六指标版也面临训练与第三层样本构成不同的问题。比如，有测值的 `mod` 有 14/34 条峰值频率低于 500 Hz，空值组只有 1/6 条，且两组的峰值频率中位数分别为 820 Hz 与 908.5 Hz。增加有测值的样本让训练数据更充足，但带来的信息对空值组作用有限。整个数据集仍只有 6 条目标 `mod`，无法据此精确估计新批次的召回率。

## 复现和预测

```bash
python -m pip install -r requirements.txt
python expanded_stage3.py train
python expanded_stage3.py predict features.csv --variant all7_stack --output predictions.csv
```

预测时可选 `all6_stack`、`all7_stack`、`all6_linear` 或 `all7_linear`。CSV 需提供 `F02`、`PulseRate`，以及第三层样本的六项实测指标。书面结果和 `results/metrics.csv` 的成绩来自折外预测，保存的 `results/models.joblib` 来自全量重训。

- `results/oof_predictions.csv` 保存 108 条记录的分支、预测和分数。
- `results/pulse_blank_mod.csv` 保存目标 6 条记录的逐条结果。
- `results/metrics.csv` 保存各模型的准确率、宏平均 F1 和分类指标。

Data01 为比赛数据的预处理版本，原数据由 [Thiebault 等](https://doi.org/10.5281/zenodo.21376648) 发布，许可为 CC BY 4.0。
