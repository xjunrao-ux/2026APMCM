# 研究覆盖范围与缺失清单

第一问要求的四部分均有对应报告。以下项目属于数据缺口、复现边界或后续研究，汇总时保留了已有证据和进度。

| 项目 | 当前状态 |
|---|---|
| F02 与脉冲率的组间比较 | F02 仅双声型有值，已作描述。脉冲率可比较有测值的调制型和双声型。平直型全空，真实空值原因无法逐条核实 |
| 企鹅个体与独立验证 | Data01 有日期和地点，缺少可核对的个体编号。现有分类评估按采集批次留出，独立录音或外部测试集验证尚未开展 |
| 原始音频的逐轨道特征 | 自然回放的轨道编号与 Data01 逐条声学特征缺少可核验的匹配键。逐轨道 Fpeak、包络调制强度、脉冲率和双基频间距对行为的独立贡献尚未估计 |
| 传播数据的录音级依赖与绝对电平 | Data03–11 提供相似度矩阵，矩阵行号用于回查，缺少可核验的录音级匹配键。现有工作计算结构相似度和阈值区间，绝对声压级衰减和实际听觉辨识距离尚未估计 |
| 后续正式模型 | 信号衰减与行为响应已完成指标选择与建模设计。本包复现第一问的描述、检验、分类和证据汇总，后续模型拟合、验证及机制实验尚未开展 |
| 原始绘图源和清洗脚本 | 两版早期雨云图以原图交付。已找到的图包只含成图。另提供从清洗后 CSV 重建分布总图的 Python 代码。既有预处理包保留清洗说明和审计表，复现入口从清洗后 CSV 开始 |

对已研究部分保留原始文件或从记录的计算步骤重建代码。新增图表仅呈现既有统计、模型对照和数据汇总。
